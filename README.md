# 📐 N-Dimensional Linear Regression

A project showcasing various techniques for solving **N-dimensional linear regression** problems. Includes methods using differential calculus, matrix operations, and an API-based approach.

## 🧠 Features

- 🔢 Multiple approaches for solving N-dimensional linear regression:
  - Direct differential calculus
  - Matrix-based solution
  - API-based regression solver
- 📊 Visualizations and comparisons of techniques
- ⚡ Optimized for educational purposes and algorithm exploration

## 🛠️ Requirements

- Python 3.8+
- NumPy, matplotlib, and other dependencies listed in `requirements.txt`

Install dependencies:
```bash
pip install -r requirements.txt
```

## 🚀 Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/ExpDev-mul/N-Dimensional-Linear-Regression.git
   cd N-Dimensional-Linear-Regression
   ```

2. Run the solution scripts:
   ```bash
   python linear_regression_calculus.py  # Differential calculus approach
   python linear_regression_matrices.py  # Matrix-based approach
   python api_regression.py              # API-based approach
   ```

## 📌 Notes

This project is ideal for learning and understanding linear regression in higher dimensions, and comparing different solution strategies.
